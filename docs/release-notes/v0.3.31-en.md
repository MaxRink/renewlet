# Renewlet v0.3.31

Renewlet v0.3.31 fixes an issue where a Cloudflare first deployment could flash past Setup and show the completed page, leaving users unable to create the first account ([#94](https://github.com/zhiyingzzhou/renewlet/issues/94), thanks [@reidmex](https://github.com/reidmex) for reporting it).

[中文 ->](./v0.3.31-zh.md)

---

## Fixes

- When the first-setup status request fails, times out, or returns invalid content, Setup no longer shows the completed page or allows admin creation. It shows an error and lets you retry.
- Login no longer shows the wrong first-deployment link or enables password login while status is unavailable. Passkey login remains available.
- Settings keeps loaded values and unsaved edits when a status refresh fails, and temporarily disables external integrations and account security actions instead of writing or clearing data.

## Improvements

- Login, Setup, and Settings share the same status request, reducing duplicate requests and allowing manual recovery after the service returns.
- Cloudflare status checks now report maintenance and incomplete deployments more clearly.
