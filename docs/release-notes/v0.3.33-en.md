# Renewlet v0.3.33

Renewlet v0.3.33 fixes two small issues in Settings and sign-out: advanced settings load more reliably, and signing out no longer leaves requests running.

[中文 ->](./v0.3.33-zh.md)

---

## Improvements

- Advanced Settings sections now finish loading when the Settings page opens. Direct links, page refreshes, and opening Settings without scrolling now show the relevant sections as expected.
- Settings directory navigation corrects the scroll position after the target section is ready, so switching between sections in quick succession is less likely to land in the wrong place.

## Fixes

- Fixed protected settings requests continuing after sign-out. Sign-out now clears the local session first and cancels unfinished queries, reducing extra 401 responses.
