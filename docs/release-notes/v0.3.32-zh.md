# Renewlet v0.3.32

Renewlet v0.3.32 修复首页“即将续费”面板漏掉提醒窗口外续费的问题。现在会按日期显示符合条件的未来事件，并区分自动续费、手动续费和提醒状态（[#96](https://github.com/zhiyingzzhou/renewlet/issues/96)，感谢 [@Flying-Ace](https://github.com/Flying-Ace) 的反馈）。

[English ->](./v0.3.32-en.md)

---

## 改进

- 首页“即将续费”现在会显示有效订阅的下一项未来事件，不再因为提醒关闭或不在提醒窗口内而消失；面板仍保持紧凑的 5 条展示。
- 自动续费、手动续费和已开启提醒的订阅会有明确的标签或图标，试用订阅会显示试用结束日期。
- 首页和日历统一使用同一套事件日期。试用结束早于正式续费时，优先显示试用结束时间。

## 修复

- 修复试用订阅只按正式续费日期展示，导致更早的试用结束日期被忽略的问题。
- 修复日历筛选只看正式续费日期，导致试用结束事件没有出现在对应日期的问题。
- 空状态文案不再暗示这里只查询提醒窗口。
