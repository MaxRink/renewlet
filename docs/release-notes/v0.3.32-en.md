# Renewlet v0.3.32

Renewlet v0.3.32 fixes the Dashboard upcoming renewals panel so renewals outside the reminder window are no longer missed. Eligible future events are shown by date, with clear auto-renewal, manual-renewal, and reminder states ([#96](https://github.com/zhiyingzzhou/renewlet/issues/96), thanks [@Flying-Ace](https://github.com/Flying-Ace) for reporting it).

[中文 ->](./v0.3.32-zh.md)

---

## Improvements

- The Dashboard now shows the next future event for every eligible subscription, including subscriptions with reminders disabled or dates outside the reminder window. The panel keeps its compact five-item limit.
- Auto-renewal, manual-renewal, and reminder-enabled states are shown clearly. Trial subscriptions show their trial end date.
- The Dashboard and calendar now use the same event date. When a trial ends before billing starts, the trial end date is shown first.

## Fixes

- Fixed trial subscriptions being shown only by their later billing date, which hid an earlier trial end date.
- Fixed calendar filtering that skipped trial end events when the billing date was later.
- Updated the empty state so it no longer implies that the panel only searches the reminder window.
