# Renewlet v0.3.31

Renewlet v0.3.31 修复 Cloudflare 首次部署后设置页一闪而过、直接进入初始化完成页的问题（[#94](https://github.com/zhiyingzzhou/renewlet/issues/94)，感谢 [@reidmex](https://github.com/reidmex) 的反馈）。

[English ->](./v0.3.31-en.md)

---

## 修复

- 首装状态请求失败、超时或返回无效内容时，设置页不再误显示完成页，也不会允许在状态未知时创建管理员；页面会显示错误并提供重试。
- 登录页在状态不可用时不再显示错误的首装入口，也不会误放行密码登录；Passkey 仍可使用。
- 设置页刷新状态失败时保留已加载的设置和未保存的修改，并暂时禁用外部集成与账号安全操作，避免误写或清空数据。

## 改进

- 登录、首装和设置页共享状态请求，减少重复请求；服务恢复后可以手动重试。
- Cloudflare 状态检查更快，维护中或部署未完成时会明确反馈当前状态。
